# Contributing

English | [简体中文](#贡献指南)

Thanks for helping! This list is data-driven: resources live in YAML files under `data/resources/`, and all README files are generated from them.

## Inclusion criteria

- Directly related to GEO / AI search visibility.
- The link works. Tools must have a usable product (no waitlist-only landing pages).
- Commercial tools are welcome but must state their pricing. No affiliate or tracking links (strip `utm_*`, `ref`, `fbclid`, `gclid`).
- Articles need real substance (not pure marketing); for near-duplicate articles from one site, keep the most representative one.
- **No GEO agencies or service providers.** Only tools, content and communities, so the list does not become an ad directory.
- The description is a single, original, objective sentence without marketing language.

## How to add a resource

1. Pick a leaf category from `data/categories.yaml` and add an entry to the matching file in `data/resources/`.
2. You only need to fill in `desc.en`. Other languages may be left empty; maintainers fill in translations in batches.
3. Do **not** edit any `README*.md` by hand. They are generated by `scripts/build.py`, and maintainers regenerate them when merging. (Maintainers: see [docs/MAINTAINING.md](docs/MAINTAINING.md).)

```yaml
- id: geo-generative-engine-optimization   # unique, kebab-case
  name: "GEO: Generative Engine Optimization"
  url: https://arxiv.org/abs/2311.09735
  category: research/foundational          # leaf category path
  type: paper    # paper | article | guide | tool | dataset | benchmark | engine | spec | community | course | video | podcast | newsletter | case-study | list
  pricing: free  # free | freemium | paid | n/a
  open_source: false
  regions: [global]
  year: 2023     # optional
  desc:
    en: Introduces GEO and a benchmark for measuring content visibility in generative engine responses.
```

Check your change locally:

```bash
pip install -r requirements.txt
python scripts/validate.py            # lenient: only desc.en is required
python scripts/validate.py --strict   # all 6 languages required (used on main)
python scripts/build.py               # regenerate READMEs (optional for contributors)
python scripts/missing.py             # list entries with missing translations
```

Descriptions: at most 200 characters for en / es / de, at most 100 for zh-CN / ja / ko.

# 贡献指南

感谢参与！本清单由数据驱动：资源写在 `data/resources/` 下的 YAML 文件中，所有 README 均由其生成。

## 收录标准

- 与 GEO（生成式引擎优化）/ AI 搜索可见性直接相关。
- 链接可访问；工具需有可用产品（不收仅有落地页的 waitlist）。
- 商业工具可收录，但必须标注价格；不接受联盟/追踪链接（去除 `utm_*`、`ref`、`fbclid`、`gclid` 等参数）。
- 文章需有实质内容（非纯营销稿）；同一站点的近似文章只收最具代表性的。
- **不收录 GEO 代理商/服务商**，只收工具、内容、社区，避免沦为广告目录。
- 描述为单句、原创、客观，不使用营销用语。

## 如何添加资源

1. 在 `data/categories.yaml` 中选择叶子分类，在 `data/resources/` 对应文件中新增条目。
2. 只需填写 `desc.en`，其余语言可留空，维护者会批量补齐翻译。
3. **不要**手动修改任何 `README*.md`，它们由 `scripts/build.py` 生成，维护者合并时会重新生成。

YAML 示例见上文。本地检查：

```bash
python scripts/validate.py            # 宽松模式：只要求 desc.en
python scripts/validate.py --strict   # 严格模式：6 种语言必须齐全（main 分支使用）
python scripts/build.py               # 重新生成 README（贡献者可不运行）
python scripts/missing.py             # 列出缺失翻译的条目
```

描述长度：en / es / de 不超过 200 字符，zh-CN / ja / ko 不超过 100 字符。
