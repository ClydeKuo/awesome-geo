# Chinese AI product names (shared by all translation guides)

Each guide in `docs/translation/` points here. Checked on 2026-11-16 against the official sites, by page title and redirects. Names change often, so re-check the official URL before adding a new engine.

## Rules

- **zh-CN** uses the "Chinese name" column.
- **ja, ko, es, de** (and en) use the "Latin / English name" column. Do not invent pinyin romanizations, and do not add the Chinese characters in parentheses.
- Always use the **current** name. Use a former name only when the source sentence is explicitly about the old product or the rename. In that case write it as e.g. `千问（原通义）` in zh, or `Qwen (formerly Tongyi)` in the other languages, translated naturally.
- If the English `desc.en` uses an outdated name, translate it with the current name and flag the entry to the maintainer.
